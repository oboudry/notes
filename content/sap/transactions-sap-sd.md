## Sales Order & Copy Controls

- `VD59` — Lister tous les numéros d'articles clients

## Copy Controls

- `VTFA` — Copy controls sales order → facture
- `VTFL` — Copy controls livraison → facture
- `VTLA` — Copy controls sales order → delivery

## Autres Copy Controls utiles

- `VTAA` — Pilotage copie cde cl. ap. cde cl.
- `VTAF` — Pilotage copie: facture apr. cde cl.
- `VTFF` — Pilotage copie Facture → Facture
- `VTFL` — Pilotage copie Livraison→Facture
- `VTLA` — Pilotage copie Cde client → Livr.
